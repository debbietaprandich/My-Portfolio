# Debbie's Digital Bloom

Create a premium, modern, highly interactive personal portfolio website for Debbie Taprandich, a Kenyan digital creator, social media/content specialist, beauty industry virtual assistant, makeup artist and certified beauty therapist.

The website should NOT look like a basic CV website. It should look like a high-end creative portfolio, personal brand website and client-conversion website designed to immediately convince brands, agencies, beauty businesses, creators and potential employers that Debbie is capable of managing social media, creating content, growing online communities and supporting beauty businesses virtually.

* Generic corporate templates
* Boring resume layouts
* Excessive text
* Stock photography
* Fake testimonials
* Fake statistics
* Generic “Lorem ipsum”
* Overly childish influencer aesthetics

Instead, make it look like a premium creative professional’s portfolio that could compete with modern creative agencies and personal-brand websites.

Think:

Personal brand + creative agency + influencer media kit + digital CV + beauty industry specialist.
