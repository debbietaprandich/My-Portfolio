# 🌟 Debbie's Portfolio

A modern, responsive, and feature-rich portfolio website built with **React**, **TypeScript**, and **Tailwind CSS**. Designed specifically to showcase high-impact visual content, social media clips, and creative projects with a sleek portrait-first card layout.

---

## ✨ Features

- **Dynamic Gallery & Category Filters:** Seamlessly filter projects by categories (Beauty, Dance, Lifestyle, Fashion, UGC, Branded Content, etc.).
- **Portrait-Optimized Card Grid:** Designed with a striking vertical phone/TikTok/Reels style layout.
- **Full-Bleed Media Displays:** Uses `object-cover` layouts to ensure images and videos fill the cards completely without letterboxing.
- **Interactive Media Viewer (Modals):** Click any card to open a full modal viewer supporting platform embeds (TikTok, YouTube) and high-resolution images.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Framework:** React & Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/debbietaprandich/debbie-portfolio.git](https://github.com/debbietaprandich/debbie-portfolio.git)


   Navigate to the project directory:

   ```

cd debbie-portfolio-main
Install dependencies:

npm install
Run the development server:

npm run dev
Open your browser and navigate to http://localhost:5173 (or the port specified in your terminal).
